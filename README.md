# Lakshit — Personal Portfolio

A playful, light-first personal portfolio with a hand-crafted illustrated hero, dark-mode toggle, responsive project cards, scroll reveals, and small interactions.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Deploy with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main** and **/(root)**, then save.
4. Wait for GitHub Pages to publish the site.

## Customisation
- All site markup, styling, and interactions are in `index.html`.
- The theme toggle remembers the visitor's preference in local storage.
- Project cards and social links point to the relevant GitHub/social profiles.
- The design respects `prefers-reduced-motion` and includes responsive layouts.

## Notes
This is a static website; it does not need API keys, a server, or a framework build step.
