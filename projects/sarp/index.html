3D browser arcade game / project 05

Sarp.

Eat. Grow. Don’t crash.

Sarp takes a familiar arcade rule set and adds depth — literally. A 21 × 21 3D arena, milestone Rainbow Apples, Fever Mode, changing weather, and procedural audio give short runs a reason to continue.

Why it exists

Problem & motivation

Classic Snake is instantly understandable, but a small game needs a fresh hook and satisfying feedback before it feels worth replaying.

The spark

I wanted to experiment with game feel: a familiar core, a dimensional presentation, escalating pace, and small surprises that reward one more round.

The approach

React manages menus, HUD, and screen flow while a Three.js game engine handles the 3D arena, effects, audio, scores, and achievements.

02

Direction

Goals and design decisions

  1. 01

    Keep the basic goal approachable: collect apples, avoid walls and yourself.

  2. 02

    Add variety without burying the original rules.

  3. 03

    Make keyboard and touch controls feel fair.

  4. 04

    Keep scores and achievements local with no account requirement.

01

Three.js arena

A 21 × 21 grid is presented in 3D with changing weather and multiple snake skins.

02

Milestone Rainbow Apples

Every 10th apple, then every 15th, triggers a short Rainbow Mode burst.

03

Layered feedback

Combos, Fever Mode, sound effects, and procedural music reinforce moment-to-moment play.

04

Local persistence

A top-five score table, achievements, and sound preference are stored in browser storage.

05

Single-file build

vite-plugin-singlefile bundles the static game into a self-contained HTML build.

Implemented

What the repository actually contains

These features are described in the project README or visible in its source and release material.

3D Snake arena

Steer through a 21 × 21 grid as the pace increases.

Special apples

Classic, Golden, Magnet, and milestone Rainbow Apples change the rhythm.

Combos & Fever

Combos, Fever Mode, multiple skins, and changing weather add variety.

Procedural sound

Music and sound effects are generated in the browser, with a mute toggle.

Local high scores

A top-five score table and achievements are saved in the browser.

Keyboard & touch

Reflection

Contribution, challenges & scope

My contribution

  • I authored and maintain the public Sarp repository under hmmlavi; the README credits the game to Lavi.
  • The repository contains React screen flow, the Three.js engine, effects, audio, scores, achievements, and utility modules.
  • It also includes gameplay screenshots and a repository social preview image.

Challenges & learning

Readable 3D
A dimensional arena still needs clear edges, apples, body segments, and a readable HUD.
Escalating pace
Speed, combos, and special apples must add excitement without making controls feel unfair.
Input coverage
Keyboard, swipe, and on-screen touch controls all need consistent pause and restart behaviour.

Documented limits

These are boundaries stated in the repository, not completed features:

  • The v1.0.0 release is a tag; no downloadable release assets are attached.
