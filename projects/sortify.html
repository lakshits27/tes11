Sortify
in the making.

A Windows utility built to make file renaming safer, clearer and easier to reverse.

View source ↗
THE STORY

The problem

Bulk file renaming can be stressful when a mistake affects dozens of files.

The approach

Sortify prioritises preview and control before applying changes, with collision handling and reversible workflows.

Key ideas & features

  • Preview planned changes before applying them.
  • Handle filename collisions instead of silently overwriting files.
  • Keep the user in control of file changes.

What I learned

Good utilities handle edge cases and respect people's files, not just the happy path.
