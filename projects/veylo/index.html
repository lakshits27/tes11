Browser app & Android shell / project 02

Veylo.

Small habits. Better days.

Veylo is a client-side habit tracker built around a simple promise: your routines stay on your device. It combines daily check-ins, a completion calendar, progress charts, and a deterministic planner without an account or backend.

01

Why it exists

Problem & motivation

Habit apps can become noisy, account-driven, or dependent on a cloud service. A personal routine tool should be easy to return to and clear about where its data lives.

The spark

I wanted a focused tracker that makes consistency visible without turning everyday progress into a competition or sending personal data elsewhere.

The approach

The same React web app powers the browser/PWA and the Capacitor Android shell. Habit state, check-ins, statistics, and planning are computed and stored locally.

02

Direction

Goals and design decisions

  1. 01

    Make daily check-ins quick and uncluttered.

  2. 02

    Show streaks, calendars, and trends without requiring an account.

  3. 03

    Suggest a realistic day with a deterministic, transparent planner.

  4. 04

    Keep personal habit data on the device by default.

01

No backend

There is no account, cloud service, or analytics pipeline behind the habit data.

02

Deterministic planning

The planner is rule-based and does not call an AI model or external API.

03

One web core

The same Vite build is used in the browser, PWA, and Capacitor Android shell.

04

Offline app shell

The installed PWA caches its shell so tracking and planning continue without a network.

05

Personal themes

Five colour themes and light, dark, or system appearance are available in Settings.

03

Implemented

What the repository actually contains

These features are described in the project README or visible in its source and release material.

Habit building

Create habits with icons, schedules, optional goals, times, reminders, and reordering.

Streaks

Check in with a tap and follow current and longest streaks over time.

Calendar & progress

Browse a monthly completion calendar and weekly, monthly, and yearly trends.

Rule-based planner

Spread selected habits across available time windows and review suggestions before applying.

Local privacy

Habits, check-ins, and preferences are stored in device browser storage.

Android APK

A Capacitor Android shell packages the same local web app for direct installation.

Reflection

Contribution, challenges & scope

My contribution

  • I authored and maintain the public Veylo repository under hmmlavi.
  • The repository includes React screens, local state/storage, date and statistics logic, and the deterministic planner.
  • It also contains PWA assets, the Capacitor Android project, icon generation, and release packaging.

Challenges & learning

Privacy versus convenience
Local storage keeps data private, but it also means there is no built-in cloud sync or backup.
Offline expectations
The PWA and Android shell need a cached app shell and network-free planning logic.
Small daily interactions
Check-ins, themes, sheets, and confirmation flows need to feel calm and predictable.

Documented limits

These are boundaries stated in the repository, not completed features:

  • Browser storage is device-specific; clearing browser or app data can erase habits.
  • There is no built-in cloud sync or backup yet.
  • The published APK is debug-signed for direct installation and preview, not a Play Store release build.
